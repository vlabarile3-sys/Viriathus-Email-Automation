Quick Guide

Core Concept

Viriathus is an advanced batch automation engine. It allows you to select multiple agents simultaneously and automatically generate personalized emails, duplicate Drive files, and write an Audit Log in a single execution.

The 3-Step Process

  • 1. Select Workflow: Choose the target group.
  • 2. Select Agents: Use the multi-select dropdown.
  • 3. Proceed & Confirm: Pick a template, select the specific target thread for each agent in the live Wizard, review the preview, and click Generate.
